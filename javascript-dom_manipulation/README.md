# JavaScript DOM Manipulation

This project uses vanilla JavaScript to select and update HTML elements,
handle click events, and add, remove, or clear list items without reloading
the page.

The scripts also use the Fetch API to display Star Wars data and translated
greetings. Scripts loaded in the document head use DOMContentLoaded to wait
for the HTML elements they need.

## Testing

Open the matching `*-main.html` example in Chrome with its script in the same
directory. The Fetch API exercises require access to the external APIs.
